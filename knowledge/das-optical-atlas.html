DAS：原理与实现方式

分点理解分布式声学传感：测到了什么、怎样获得信号、有哪些代表性实现，以及如何解释。

测量什么测量过程实现方式元件作用解释边界参考来源

01先理解：它测量什么

  • 测量对象通常测量沿光纤的动态轴向应变或应变率；应变、应变率与声压之间不能直接画等号。
  • 基本机制窄线宽光在光纤中产生瑞利背散射。光程扰动改变散斑强度、相位或局部频谱；不同路线读取的信息不同。
  • 位置定位脉冲 OTDR 用往返时延定位；连续扫频 OFDR 用拍频定位。两者的位置编码方式不同。
  • 解释前提光缆与介质的机械耦合、标距、偏振衰落及仪器输出单位，决定信号能解释到哪一层。

02测量过程：从光到结果

  1. 发射光
  2. 沿纤瑞利散射
  3. 接收强度或复光场
  4. 相位/谱移解调
  5. 标定与物理解释

01强度直检 φ-OTDR / DVS

  • 工作方式脉冲回波直接进入光电接收器，比较各位置的散斑强度变化。
  • 直接观测瑞利散斑强度变化
  • 适用条件与局限强度与相位一般是非线性关系，可定位振动，不能仅凭强度差直接换算定量应变。
代表性光路与关键公式
  1. 关键关系 / Key relation
    i=R |Br|²; D=i(t,T)-i(t,T0)
  2. 关键关系 / Key relation
    z=c(t-t0)/(2ng)

依据：Juarez et al., J

02外差相干 φ-OTDR

  • 工作方式回波与同源连续本振混频，用平衡探测和电域下变频恢复复光场。
  • 直接观测外差拍频的 I/Q 与相位
  • 适用条件与局限低通须保留扰动带宽，并校正本振、接收链和偏振衰落。
代表性光路与关键公式
  1. 关键关系 / Key relation
    idiff=2R Re[Br BL*]
  2. 关键关系 / Key relation
    C_hat=LPF[idiff exp(-iΩA t)]/R; φ=arg(C_hat)

依据：Dong et al., Applied Optics 55, 7810–7815 (2016).

03零差相干 φ-OTDR

  • 工作方式用 90° 光学混频器及两对平衡探测器，直接得到两条正交电信号。
  • 直接观测同频相干 I/Q 与相位
  • 适用条件与局限校正 I/Q 偏置、增益差及正交误差；Q 端口顺序改变时相位符号也改变。
代表性光路与关键公式
  1. 关键关系 / Key relation
    C_hat=(I+iQ)/R
  2. 关键关系 / Key relation
    φ=atan2(Q,I)

依据：Wang et al., Optics Express 24, 853–858 (2016).

04延迟 MZI 与 3×3 耦合器

  • 工作方式回波分到两条延迟不同的支路，再由 3×3 耦合器形成三条相移干涉信号。
  • 直接观测两散射区之间的相位差
  • 适用条件与局限标距由臂时延差设定，脉宽决定的空间分辨率另行定义；需校准三通道增益和端口相移。
代表性光路与关键公式
  1. 关键关系 / Key relation
    φ=atan2[sqrt(3)(i1-i2), 2i0-i1-i2]
  2. 关键关系 / Key relation
    Lg=c τd/(2ng)

依据：Phase Error Evaluation via Differentiation and Cross-Multiplication Demodulation in Phase-Sensitive OTDR, Photonics 10, 514 (2023).

05非平衡 Michelson 与 PGC

  • 工作方式反射式双臂由法拉第旋转镜返回，在一臂施加相位载波，读取前两谐波。
  • 直接观测相位载波的谐波系数
  • 适用条件与局限有效调制深度是双程量；载波与采集需同步，避开贝塞尔系数接近零的工作点。
代表性光路与关键公式
  1. 关键关系 / Key relation
    i=I0+V cos(φ-C cos x)
  2. 关键关系 / Key relation
    h1=2V J1(C) sinφ; h2=-2V J2(C) cosφ

依据：Liu et al., Distributed Acoustic Sensing With Michelson Interferometer Demodulation, Photonic Sensors (2017).

06双脉冲自外差 φ-OTDR

  • 工作方式同源光产生频率不同、发射时刻不同的一对脉冲，使回波在接收时相互干涉。
  • 直接观测两回波之间的拍频相位
  • 适用条件与局限两路 RF 的时钟、门控与相对初相需要锁定，并选择回波重叠区。
代表性光路与关键公式
  1. 关键关系 / Key relation
    ΔΩ=Ω1-Ω2
  2. 关键关系 / Key relation
    C_hat=LPF[i exp(-iΔΩt)]/R; Lg≈c ΔTpair/(2ng)

依据：He et al., Optics Letters 42, 442–445 (2017).

07啁啾脉冲 CP-φ-OTDR

  • 工作方式在一个脉冲内部线性扫频，对前后强度迹线做局部相关，估计等效频谱平移。
  • 直接观测局部迹线时间平移 δu
  • 适用条件与局限须标定啁啾斜率、保持足够相关，并控制温度交叉敏感。相关滞后符号取决于定义。
代表性光路与关键公式
  1. 关键关系 / Key relation
    IT(u)≈I0(u+δu); ΔνR=-κ δu
  2. 关键关系 / Key relation
    Δε=κ δu/[ν0(1-pe)] (ΔT=0)

依据：Pastor-Graells et al., Optics Express 24, 13121–13133 (2016).

08频率扫描 FS-φ-OTDR

  • 工作方式在脉冲之间逐频扫描，为每个位置构造局部瑞利频谱，再与参考谱相关。
  • 直接观测局部瑞利频谱平移 ΔνR
  • 适用条件与局限一轮频扫期间状态需近似不变；串行频扫降低更新速率。
代表性光路与关键公式
  1. 关键关系 / Key relation
    Δε=-ΔνR/[ν0(1-pe)] (ΔT=0)
  2. 关键关系 / Key relation
    fupdate≲frep/Nν

依据：Zhang et al., Optics Letters 45, 5020–5023 (2020).

09扫频相干 OFDR

  • 工作方式连续扫频光与参考光干涉，用辅助 MZI 校正扫描后转换为空间复回波。
  • 直接观测距离相关拍频与空间复回波
  • 适用条件与局限与脉冲 OTDR 不同；需校准参考延迟和拍频符号，动态相位测量要求一次扫描内扰动近似不变。
代表性光路与关键公式
  1. 关键关系 / Key relation
    fb=κ(τz-τref); z=c(τref+fb/κ)/(2ng)
  2. 关键关系 / Key relation
    Δzideal≈c/(2ng Δνsweep)

依据：Zhou, Chen & Bao, Applied Optics 55, 6735–6739 (2016).

04主要元件：各自起什么作用

  • 光源与发射控制激光器提供光；调制器产生脉冲、频移或扫频；驱动与偏置控制决定实际发射波形。
  • 光路与光纤耦合器分光或混频，环形器区分发射与回波，光纤提供分布式散射；光学滤波按谱带选型。
  • 接收与采集探测器把光信号转为电信号，采集卡或时间标记器记录信号；带宽、增益和同步均需校准。
  • 处理与标定上位机完成比值、谱拟合或相关解调，再用参考温度、应变灵敏度和安装信息赋予物理量。

05解释时需要区分什么

  • 空间尺度空间分辨率、应变标距与输出采样间距分别定义；密集输出点不代表更高的真实分辨率。
  • 相位与应变采用原项目的 exp(+iωt) 约定和远端减近端相位差时，Δεavg=-Δφg/(Kε Lg)，Kε=4πneff(1-pe)/λ。端口顺序、温度变化和解调符号需校准。
  • 交叉敏感温度、应变与机械耦合可能同时影响读数。先确认仪器的直接观测，再讨论目标物理过程。
  • 验证层次这些光路与关系式用于原理说明；代数校验不等于仪器性能验证，也不等于现场解释成立。
