DSS：原理与实现方式

分点理解布里渊和瑞利应变测量，比较时域、频域与相关域定位，并说明温度补偿和应变传递。

测量什么测量过程实现方式元件作用解释边界参考来源

01先理解：它测量什么

  • 测量对象测量光纤自身的轴向应变或应变变化。光纤应变不自动等于围岩、套管或结构应变。
  • 两类主要机制布里渊路线估计局部 BFS；瑞利路线比较参考与当前散射指纹，估计局部谱移。
  • 温度交叉敏感ΔνB = Cε Δεfiber + CT ΔT。只有一个频移时，需要独立温度信息或明确约束才能计算应变。
  • 应变传递涂覆、黏结、光缆结构、滑移与剪滞影响 εfiber 到 εhost 的关系；温度补偿不能替代机械耦合验证。

02测量过程：从光到结果

  1. 发射/参考状态
  2. 局部散射谱
  3. 频移或谱相关
  4. 温度补偿
  5. 光纤应变与传递验证

03代表性实现方式

每一种方式分别说明测量机制、直接观测与适用条件。光路示意和关键公式可按需展开。

01自发布里渊 BOTDR

  • 工作方式单端发射脉冲；回波与同源频移本振相干检测，逐位置恢复 BFS。
  • 直接观测自发布里渊回波频谱中心
  • 适用条件与局限自发散射信号弱，通常需要平均与扫频/谱估计；单端可达不意味着温度与应变自动分离。
代表性光路与关键公式
  1. B0 → Bp / BL · 分支 / Branches
    Bp(t)=sqrt(Pp)a(t)exp(i2πν0t); BL(t)=sqrt(PL)exp(i2πνLOt)

    一支生成脉冲，一支保留为本振；不需要从远端注入连续探测光。

  2. BBS + BL → i · 相干接收 / Coherent reception
    νLO=ν0-νoffset; fIF ≈ |νoffset-νB(z)|

    Stokes 回波约为 ν0-νB；本振经单边带频移与滤波，把 GHz 量级布里渊光频差转到接收器带宽内。频移量与增减方向需标定。

  3. 时窗 → z · 定位 / Localization
    z=c(t-t0)/(2ng); Δzpulse ≈ cτp/(2ng)

    按往返时延分窗，估计每窗频谱。脉宽与声子寿命会影响空间响应和谱宽。

  4. ΔνB · 温度与应变 / Cross-sensitivity
    ΔνB = Cε Δεfiber + CT ΔT

    相对于参考状态的小变化模型。Cε 的单位为 Hz/单位应变（或 MHz/με），CT 为 Hz/K；不能混用单位或把单一频移当作两个未知量。

  5. 解耦 / Compensation
    Δεfiber=(ΔνB-CT ΔT)/Cε; ΔT=(ΔνB-Cε Δεfiber)/CT

    应变测量需要独立温度信息；测温需要已知或隔离的光纤应变。光缆热膨胀与约束会改变有效标定。

依据：Kurashima et al

02受激布里渊 BOTDA

  • 工作方式泵浦脉冲与连续探测光反向传播，在逐位置增益谱中估计应变。
  • 直接观测局部增益谱与 BFS
  • 适用条件与局限通常需光纤两端可达或形成回路；泵浦耗尽、非局部效应、偏振与温度交叉敏感均须控制。
代表性光路与关键公式
  1. B0 → Bp / Bs · 光源 / Source
    Bp(t)=sqrt(Pp) a(t) exp(i 2πνp t); Bs(t)=sqrt(Ps) exp(i 2πνs t)

    同源泵浦与探测支路分开。探测光经单边带调制及选边带滤波，下移到 νs=νp-Δν；两束在光纤中反向传播。

  2. G(z,Δν) · 增益谱 / Gain spectrum
    gB(z,Δν)=g0(z)/{1+[2(Δν-νB(z))/ΓB(z)]²}

    弱增益、近稳态条件下用洛伦兹线型拟合局部谱。强泵浦耗尽、脉冲瞬态及谱重叠会破坏简化模型。

  3. i(t,Δν) → νB(z) · 定位 / Localization
    Gmeas(z,Δν) ≈ ln[Ps,on/Ps,off]; z = c(t-t0)/(2 ng)

    按触发时延定位，并扫描泵浦与探测频差 Δν；每个 z 拟合 Brillouin frequency shift，简称 BFS。

  4. ΔνB · 温度与应变 / Cross-sensitivity
    ΔνB = Cε Δεfiber + CT ΔT

    相对于参考状态的小变化模型。Cε 的单位为 Hz/单位应变（或 MHz/με），CT 为 Hz/K；不能混用单位或把单一频移当作两个未知量。

  5. 解耦 / Compensation
    Δεfiber=(ΔνB-CT ΔT)/Cε; ΔT=(ΔνB-Cε Δεfiber)/CT

    应变测量需要独立温度信息；测温需要已知或隔离的光纤应变。光缆热膨胀与约束会改变有效标定。

依据：Horiguchi & Tateda (1989)

03差分脉宽对 DPP-BOTDA

  • 工作方式用共同起点、不同宽度的两组脉冲测量，差分提取短尾段的局部贡献。
  • 直接观测两条增益迹线之差
  • 适用条件与局限不能把小脉宽差当作无条件空间分辨率；两次采集中的状态变化会产生差分伪影。
代表性光路与关键公式
  1. B0 → Bp / Bs · 光源 / Source
    Bp(t)=sqrt(Pp) a(t) exp(i 2πνp t); Bs(t)=sqrt(Ps) exp(i 2πνs t)

    同源泵浦与探测支路分开。探测光经单边带调制及选边带滤波，下移到 νs=νp-Δν；两束在光纤中反向传播。

  2. G1 / G2 → Gdiff · 差分 / Difference
    Gdiff(z,Δν)=Gτ1(z,Δν)-Gτ2(z,Δν); τ1>τ2

    两组迹线先做时间对齐和功率归一；相同前沿条件下差值提取长脉冲尾段。

  3. 尾段尺度 / Tail-interval scale
    Δzideal ≈ c(τ1-τ2)/(2ng)

    这是理想差分门宽尺度；实际受脉冲边沿、接收带宽、声学瞬态与减法噪声限制。

  4. ΔνB · 温度与应变 / Cross-sensitivity
    ΔνB = Cε Δεfiber + CT ΔT

    相对于参考状态的小变化模型。Cε 的单位为 Hz/单位应变（或 MHz/με），CT 为 Hz/K；不能混用单位或把单一频移当作两个未知量。

  5. 解耦 / Compensation
    Δεfiber=(ΔνB-CT ΔT)/Cε; ΔT=(ΔνB-Cε Δεfiber)/CT

    应变测量需要独立温度信息；测温需要已知或隔离的光纤应变。光缆热膨胀与约束会改变有效标定。

依据：Li et al

04布里渊频域 BOFDA

  • 工作方式连续泵浦以小幅正弦强度调制；测量探测光响应的幅度与相位，再转为空间响应。
  • 直接观测小信号复传递函数 H(fm,Δν)
  • 适用条件与局限傅里叶反演需有限带宽窗函数、参考去嵌入及声学响应考虑；不是把 BOTDA 的时间轴简单换个名字。
代表性光路与关键公式
  1. Bp · 小信号调制 / Small-signal modulation
    Pp(t)=P0[1+m cos(2πfmt)]; m≪1

    扫描电学调制频率 fm，同时扫描光学泵浦-探测频差 Δν；两种频率不能混淆。

  2. H · 复响应 / Complex response
    H(fm,Δν)=δPs(fm,Δν)/δPp(fm)

    VNA 或同步锁相测量相对发射调制的幅度与相位，不能仅测平均光强。

  3. H → h(z) · 空间反演 / Spatial reconstruction
    h(τ,Δν)=IFTfm[H]; z=cτ/(2ng)

    延迟零点取决于系统参考；Δz≈c/(2ng Bm)，无歧义距离≈c/(2ng δfm)，均为理想尺度。

  4. ΔνB · 温度与应变 / Cross-sensitivity
    ΔνB = Cε Δεfiber + CT ΔT

    相对于参考状态的小变化模型。Cε 的单位为 Hz/单位应变（或 MHz/με），CT 为 Hz/K；不能混用单位或把单一频移当作两个未知量。

  5. 解耦 / Compensation
    Δεfiber=(ΔνB-CT ΔT)/Cε; ΔT=(ΔνB-Cε Δεfiber)/CT

    应变测量需要独立温度信息；测温需要已知或隔离的光纤应变。光缆热膨胀与约束会改变有效标定。

依据：Garus et al

05布里渊相关域 BOCDA

  • 工作方式共同频率调制的泵浦与探测光在特定位置形成频差匹配区；移动相关峰扫描光纤。
  • 直接观测相关峰附近的局部增益谱
  • 适用条件与局限多个相关峰、背景增益与扫描位置标定决定可用范围；通常需要两端接入，不能沿用 OTDR 的脉冲时延公式定位。
代表性光路与关键公式
  1. B0 → Bp / Bs · 共同调制 / Common modulation
    ν(t)=ν0+Δf sin(2πfmt); νs(t)=ν(t)-Δν

    对同源泵浦与探测施加相关频率调制，支路延迟决定相关峰位置。

  2. 局部相关 / Local correlation
    δνlocal(z,t)=Δν+ν(t-τp(z))-ν(t-τs(z))

    当两路调制在某位置对齐，局部频差较稳定；其他位置谱展宽形成背景。

  3. 峰距 / Peak spacing
    dpeak≈c/(2ngfm); Δz ∝ 1/(fm Δf)

    这是正弦 FM 实现的峰距及分辨率趋势；比例系数取决于线宽、调制与门控，须依据实际实现计算。

  4. ΔνB · 温度与应变 / Cross-sensitivity
    ΔνB = Cε Δεfiber + CT ΔT

    相对于参考状态的小变化模型。Cε 的单位为 Hz/单位应变（或 MHz/με），CT 为 Hz/K；不能混用单位或把单一频移当作两个未知量。

  5. 解耦 / Compensation
    Δεfiber=(ΔνB-CT ΔT)/Cε; ΔT=(ΔνB-Cε Δεfiber)/CT

    应变测量需要独立温度信息；测温需要已知或隔离的光纤应变。光缆热膨胀与约束会改变有效标定。

依据：Hotate & Hasegawa (2000)

06瑞利 OFDR 应变测量

  • 工作方式扫频干涉给出距离，再用局部瑞利谱相关估计轴向光纤应变变化。
  • 直接观测相对参考状态的局部谱移
  • 适用条件与局限需要保存参考指纹、选择标距并校准温度；局部相关失败时应标记缺测，不能自动填成可靠应变。
代表性光路与关键公式
  1. B0 → B1 / BL · 分光 / Split
    ν(t)=ν0+κt; B1 ∝ exp[i2π∫ν(t)dt]; BL is the reference field

    扫频光分为测量与参考支路；辅助不等臂 MZI 提供扫频时钟。κ 为实际光频扫描速率。

  2. B2 + BL → i · 拍频 / Beat
    i(t) ∝ 2 Re[B2(t) BL*(t)]; fb=κ τrel

    回波与参考光相干混频。τrel 是相对参考支路的延迟，需要零点标定，不能默认全部距离从光源开始。

  3. i → r(z) · 空间变换 / Spatial transform
    z-zref = c fb/(2 ng κ); Δzideal ≈ c/(2 ng Bν)

    按实际光频重采样后作傅里叶变换。Bν 是光频扫描带宽；上述理想分辨率不等于应变标距。

  4. r0 / r1 → q · 指纹相关 / Fingerprint correlation
    δν(z)=argmaxδ Corr[S0(z,ν), S1(z,ν+δ)]; q=-δν/ν0

    在相同窗口内比较参考与当前瑞利指纹；δν 是当前谱相对参考的有符号光频移。通常拉伸导致红移 δν<0，因此 q>0；须按实际相关实现核对符号。

  5. q → Δε / ΔT · 解耦 / Compensation
    q = Kε Δεfiber + KT ΔT

    Kε、KT 按此符号约定实测标定；普通硅纤中通常为正。温度和应变同时变化时需第二个独立观测。

依据：Froggatt & Moore (1998)

07频率扫描相干 OTDR

  • 工作方式对多个稳定光频分别发射脉冲，用时延定位、频率扫描构建局部指纹，再相关求应变。
  • 直接观测每个距离窗的瑞利频谱移
  • 适用条件与局限频扫相干 OTDR 的谱移法与常见 DAS 相位法不同；扫描时长、频率稳定度和相关窗限制动态测量。
代表性光路与关键公式
  1. B0 → Bp / BL · 逐频发射 / Frequency stepping
    νm=ν0+m δν; Bp,m(t)=a(t)exp(i2πνmt)

    光频在各次脉冲之间步进，单次脉冲内保持近似稳定；不同于连续扫频 OFDR。

  2. i(t,νm) → S(z,νm) · 指纹 / Fingerprint
    z=c(t-t0)/(2ng); S(z,νm)=local Rayleigh signature

    空间位置由脉冲时延给出；光频轴用于局部指纹相关，不用于 OFDR 距离拍频公式。

  3. r0 / r1 → q · 指纹相关 / Fingerprint correlation
    δν(z)=argmaxδ Corr[S0(z,ν), S1(z,ν+δ)]; q=-δν/ν0

    在相同窗口内比较参考与当前瑞利指纹；δν 是当前谱相对参考的有符号光频移。通常拉伸导致红移 δν<0，因此 q>0；须按实际相关实现核对符号。

  4. q → Δε / ΔT · 解耦 / Compensation
    q = Kε Δεfiber + KT ΔT

    Kε、KT 按此符号约定实测标定；普通硅纤中通常为正。温度和应变同时变化时需第二个独立观测。

  5. 补偿后应变 / Compensated strain
    Δεfiber=(q-KT ΔT)/Kε

    同样需要温度补偿与参考状态；整个频率扫描期间应变变化会破坏准静态假设。

依据：Koyamada et al

04主要元件：各自起什么作用

  • 光源与发射控制激光器提供光；调制器产生脉冲、频移或扫频；驱动与偏置控制决定实际发射波形。
  • 光路与光纤耦合器分光或混频，环形器区分发射与回波，光纤提供分布式散射；光学滤波按谱带选型。
  • 接收与采集探测器把光信号转为电信号，采集卡或时间标记器记录信号；带宽、增益和同步均需校准。
  • 处理与标定上位机完成比值、谱拟合或相关解调，再用参考温度、应变灵敏度和安装信息赋予物理量。

05解释时需要区分什么

  • 空间尺度空间分辨率、应变标距与输出采样间距分别定义；密集输出点不代表更高的真实分辨率。
  • 交叉敏感温度、应变与机械耦合可能同时影响读数。先确认仪器的直接观测，再讨论目标物理过程。
  • 验证层次这些光路与关系式用于原理说明；代数校验不等于仪器性能验证，也不等于现场解释成立。
